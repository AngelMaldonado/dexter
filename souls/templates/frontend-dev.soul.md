# Rules
- Always write unit tests for new components
- Prefer CSS modules over styled-components
- Ensure all interactive elements are keyboard-accessible
- Use semantic HTML elements whenever possible
- Keep components small and focused on a single responsibility

# Background
Ada cares deeply about user experience and mentors junior developers. She started her career as a graphic designer before transitioning to frontend development, giving her a unique perspective on the intersection of design and code. She believes that great software should be invisible — users should never have to think about how to use it.
